# Dataset

## avocado.csv

Hass Avocado Board retail scanner data. Weekly prices and volumes across 54 U.S. regions, January 2015 – March 2018.

**Source:** [Kaggle – Avocado Prices](https://www.kaggle.com/datasets/neuromusic/avocado-prices)

**Columns:** Date, AveragePrice, Total Volume, 4046, 4225, 4770, Total Bags, Small Bags, Large Bags, XLarge Bags, type, year, region

If the file is missing, run from project root: `source("scripts/fetch_or_generate_data.R")` to generate synthetic data.
